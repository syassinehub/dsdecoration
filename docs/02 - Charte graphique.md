# Charte graphique
Retour : [[00 - Projet DS DECORATION]]

Couleurs extraites des pixels du logo :

| Rôle | Couleur |
| --- | --- |
| Orange | `#f6821f` |
| Rouge | `#e03a3e` |
| Violet | `#963d97` |
| Vert (feuille) | `#62bb47` |
| Encre (texte/fonds sombres) | `#1d1d24` |
| Papier (fonds clairs) | `#faf8f5` |

Dégradé signature : orange → rouge → violet (boutons, bandeaux, soulignés).
Chaque métier a sa couleur : revêtement = orange, peinture = rouge, tapisserie = violet, plâtrerie = vert.

Typographies (Google Fonts) : **Outfit** pour les titres, **Lato** pour le texte (proche de la signature du logo).

Logos dérivés : `logo.png` (fond transparent), `logo-white.png` (texte blanc pour fonds sombres), `favicon.png` (pictogramme seul).
